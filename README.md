# Game Design Experiments

This repository is intended to contain personal game-development experiments, small gameplay prototypes, UI experiments, and reusable code.

The purpose of this repository is to share projects that others may study, modify, adapt, or use as inspiration for their own work. The repository may include projects created with tools such as GameMaker, C++, or other game-development technologies.
